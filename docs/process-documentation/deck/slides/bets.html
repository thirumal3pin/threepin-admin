Ruling the sector · six bets · first step inside three months

Six bets, each with a first step

3 PIN Chennai Index

A monthly public price and demand index by street, society and configuration — the quoted source for Chennai prices in press, AI answers and banks.

First step: publish 10 localities from existing data, in Tamil and English

Property Passport

A living record per property: verified documents, measurements, plan, tour, every valuation, rental history — handed to the next owner.

First step: start one for every verified listing and managed unit

Transparent bidding

For priced-to-sell exclusives: a time-boxed, verified-buyer offer window run by Eåsy; the seller sees every offer.

First step: pilot on 3 exclusives with the matched-buyer base

Sell-in-30

Exclusive + verified + full media + bidding + matched outreach, with a published 30-day target and a fee reduction if missed — a promise competitors cannot make.

First step: define terms; run with 5 sellers; publish results

3 PIN Partner network

Independent brokers run on Eåsy, the price desk, verification and the media pipeline under a revenue share; shared, verified inventory.

First step: onboard 5 brokers on the multi-tenant platform, already built

NRI desk

Verification, management, value reports and remote selling with e-sign and video registration support — Chennai's highest trust-deficit segment.

First step: package management, verification and e-sign; 10 clients

Four more bets sit in the strategy: an investor-backed instant-offer bridge (buy at the price-desk floor within 7 days, resell with our media and buyers), Eåsy for buyers and owners as a consumer edition (WhatsApp first), data products for developers and lenders, and rent-to-own on managed vacant stock. Sell-in-30 is highlighted because it bundles everything the plan builds into one promise a seller can understand.
