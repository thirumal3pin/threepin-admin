No more than three builds in development at once; a wave starts only when the last one's exit is met or the owner records why.

Each wave holds four to six M- or L-sized builds, sequenced so that no more than three are in development at the same time; the small items ride along. Every release passes the same gate as today (review → fix → re-review → tests → rules → push), every feature has a kill switch, and hires follow the same wave gates. Wave 0 comes first because every later agent reads the fact store and the DPDP consent texts and flags must exist before any recorded call or outreach; it also carries the fix-now release from the system audit. What would make the plan fail: channels before facts, automated first contact before consent, AI deciding prices or Won, media without measurement, management without operations, fixed costs added too early in a slowdown, too many parallel bets.
