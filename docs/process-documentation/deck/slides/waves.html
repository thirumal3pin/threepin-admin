Each wave: three or four initiatives in flight, one release gate as today (review → fix → re-review → tests → rules → push), a kill switch and a daily AI budget per feature. Wave 0 comes first because every later agent reads the fact store and the DPDP consent texts and flags must exist before any recorded call or outreach. Wave 1 pays for itself with one extra deal a month. The development chain runs alongside: mandate targets by December, first mandates by March, first JV by June. What would make the plan fail: channels before facts, automated first contact before consent, AI deciding prices or Won, media without measurement, management without operations, too many parallel bets.
